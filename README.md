# Ritish Singha — Software Engineer Portfolio

Live Demo: [https://ritish-portfolio-rs.vercel.app/](https://rsingh-portfolio.vercel.app/)

A modern, high-performance developer portfolio featuring an interactive terminal, recruiter fast-pitch mode, live CV previewer, 3D interactive skill sphere, audio effects, and ambient music widget.

---

## ✨ Features

- **Recruiter "Fast View" Mode**: 1-minute elevator pitch with degree stats, core stack, ICPC/Codeforces highlights, and quick contact buttons.
- **In-Browser PDF CV Preview**: Instant modal preview and download of CV.
- **Interactive Terminal (REPL)**: macOS-style glassmorphic terminal with `Tab` auto-completion, command history, dynamic theme switcher (`theme cyberpunk | tokyo | emerald`), and system status.
- **Project Detail Modals**: Glassmorphism cards breaking down problems, solutions, architecture, and GitHub links.
- **RS AI Assistant**: Simulated interactive chatbot answering visitor questions.
- **Native Web Audio FX**: Zero-dependency UI micro-sounds generated via the Web Audio API.
- **3D Skill Sphere**: Interactive 3D tech tag cloud powered by TagCloud.js.
- **Currently Coding Widget**: Vinyl record music player with lofi playlist.

---

## 🛠 Tech Stack

- **Core**: HTML5, Modern CSS3, JavaScript (ES6+)
- **Icons & Typography**: [Lucide Icons](https://lucide.dev/), Outfit, Inter, JetBrains Mono
- **Deployment**: [Vercel](https://vercel.com/) (Edge Network CDN)

---

## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/ritishsingha999/rs-portfolio.git

# Navigate to project folder
cd rs-portfolio

# Run a local HTTP server
python -m http.server 3000
# or
npx serve .
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
